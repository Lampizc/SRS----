### 3.3 逐周填实现（11.9 – 12.13，按确定性优先级）

1. **array.py（11.9–11.22）**：把契约里的坐标链/流形/波束域参考实现正式化。
   - 单测逐函数覆盖，与契约自检对齐（符号约定、酉归一化、能量守恒）；
   - demo：单用户方向 → 波束域峰值落在 `rint(N·ψ)`。
2. **scene.py（11.23–12.06）**：轨道几何 + 布局 + 真值。
   - 圆轨道 ECEF 传播 → `SatelliteTrack`（slots 单调、形状守卫）；
   - 服务区/可见性/过境时长，与手算值对拍（853 km、52.3°）；
   - 三布局 × 三移动生成器：同 (layout, n_users, seed) 逐位可复现；u,v 必须**按圆盘采样再转角**（契约第 2 节的警告，不能对 u、v 独立采样）；
   - `TruthTable` 只给仿真器与 metrics。
   - **布局打样**：uniform 布局我写样板，hotspot / corridor 请同学 C、D 各打样一个，我 review 合并——让他们提前建立模块 1 的手感，服务第 6 月交换讲解。
3. **obs.py（12.07–12.13）**：观测生成与 `Observation` 组装。
   - 噪声严格按契约 SNR 口径（σ² = |g|²·N_ant / SNR_array）；
   - `observe()`：Scene + slot + uids + window + srs + theta_pred → Observation（形状守卫全开）；
   - 泄漏自查：est/group/sched 里 grep 不得出现 "truth"。
4. **SRS 标准映射（12.07–12.13，可压缩）**：`SRSConfig` 参数 ↔ 3GPP TS 38.211/38.214 资源格的对应表，先做文档级映射，仿真暂不逐符号实现 comb/跳频波形。

每完成一个函数即补：单测 + demo 脚本 + README 一段（怎么跑/输入输出/已知限制）。**不做"只有我能跑"的私有代码。**
