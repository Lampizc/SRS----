## 接口契约代码（已产出）
- `srs_track/contract.py`（1515 行，CONTRACT_VERSION 1.0.0）+ `srs_track/__init__.py`（PEP 562 惰性导出）。
- 特意不叫 types.py：会顶掉标准库 types，导致 numpy 等内部导入随机报错。这个坑已写进文件头注释。
- 已定死的约定（改动前必须跑自检）：
  - 坐标链：方向余弦 (u,v) → ψ=(d/λ_ul)u → 波束索引 k=N·ψ（k∈[-N/2,N/2)）
  - 流形 a[m]=exp(+j2πψm)，平铺 i=m_u·N_v+m_v；DFT 列=conj(a)=接收权
  - 波束域 = fft2(y)/sqrt(N_ant)（酉归一化，去掉会让 SNR 差 N_ant 倍）
  - SNR：σ²=|g|²N_ant/10^(dB/10)，单符号阵列级；L 符号增益 10log10(L)
  - CRB 口径：crb_radius=sqrt(trace(CRB)) RMS；99% 半径 = 2.146×RMS（Rayleigh 系数，已 MC 验证）
  - 资源：一组共用 L 符号记 L 单位（不管几人）；基线正交记 L×人数
  - 误差预算 T_max=(ε-σ_meas-b_fixed)/pred_rate - 处理延迟；不可行返回 0
