## 技术约定（已冻结在 srs_track/contract.py）
- 坐标链：(u,v) → ψ=(d/λ_ul)·u → 波束索引 k=N·ψ，k ∈ [-N/2, N/2)
- 流形 a[m]=exp(+j2πψm)，平铺 i=m_u·N_v+m_v；DFT 列 = conj(a) = 接收权
- 波束域 = fft2(y)/√N_ant（酉归一化，不可省）
- SNR：σ²=|g|²·N_ant/10^(dB/10)，单符号、阵列级；L 个符号增益 10log10(L)；**σ² 是每阵元复噪声总方差 E|n|²（每实数维 σ²/2），按"每维 σ²"生成会低 3 dB**（2026-11-05 修订表述）
- CRB 口径：crb_radius = √(trace(CRB))，RMS 半径；99% 半径 = 2.146 × RMS
- 资源计数：一组共用测 L 符号记 L 单位（与人数无关）
- 误差预算：T_max = (ε − σ_meas − b_fixed)/pred_rate − 处理延迟

- 契约经独立复核（2026-11-05，第 3 轮）：几何/SNR/符号/能量/平铺全对，仅修 2 处文档不一致（文件头版本号、σ² 表述），接口零改动
